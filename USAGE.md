Start emulator

```
./src/uarm/cp-uarm roms/Palm-Tungsten-C-nor.bin
```

Installing a PRC: type this at the cp-uarm prompt in the terminal while the emulator is running:

```
install /path/to/app.prc
```

Then press F5 (Home) to see the app in the launcher.

Keys:

```
Host key	Tungsten C
F1 – F4	Date Book, Address, VersaMail, Web buttons

Cursor keys, Enter	5-way navigator (up/down/left/right, select)

F5 or Home	Home
F6	Menu (press again to close)
```
